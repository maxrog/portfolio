{% section_title Contributions & Takeaways %}

{% textalign left %}
The Dewey's app is a tool used for them to keep customers up to date on their events and general information about the establishment. 

**Takeaways**  
* **Firebase CMS** Used to send push notifications to users about daily specials etc.  
* **Google Calendar** Their Google Calendar data is pulled and filtered to display data. 
* **Unit Testing** Unit testing for Realm, network, and manager classes.
{% endtextalign %}

{% textalign left %}
This app is simple at it's core. That means it lent an opportunity for me to work towards a clean, crisp UI/UX. I also used it to help get more experience with unit testing. 
I was given permission from the client to make the code available on [GitHub](https://github.com/maxrog/DeweysRacine "https://github.com/maxrog/DeweysRacine").
