{% textalign left %}
The RUSD app's main feature is to enable staff (particularly IS) to view relevant messages. It allows the client to log in to a web portal and send out push notifications to relevant topics (training, outages, etc) and update contact information. This project consisted of an iOS, Android, and Web component. The iOS component is deployed on an enterprise developer account to distribute internally to their employees.  
**Takeaways**  
* **User Authentication** Logging in through our Node.js/MongoDB backend which communicates with RUSD's LDAP system to authenticate the user.  
* **Handling Tokens** Logic to check if a refresh is needed and what to do on failure. Keeping our server updated on any updated registration tokens received through Firebase. Securely storing access tokens on authentication success.   
* **Subscription Logic** User's are allowed to choose their subscription level by opting in to their location only, district-wide, or unsubscribe all together. This data along with user employment changes is actively synced with our server via HTTP Post requests. Our notifications were also filtered client side for viewing purposes.
