{% section_title Contributions & Takeaways %}

{% textalign left %}
Kenosha Farmers Market was built to allow local market goers to see market availability and explore them in an easy way. Initially it was supposed to have a second phase which provided our client with an admin portal to add content and send push notifications for events but it fell through.  
**Takeaways**  
* **CoreLocation** to display the distance to the different markets
* Designing a filter to repopulate the map instantly
* Designing the UI to display nicely on all screen sizes
{% endtextalign %}

{% textalign left %}
This was a very simple app to make due to the fact that phase two was cut. Also, the map scene functionality was similar to the Frank Lloyd Wright app, allowing me to reuse code where possible.  
**Moving Forward**: Maintenance
